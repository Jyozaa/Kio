# Local model

Kio uses MLX Swift LM 3.31.4 with `mlx-community/Qwen3.5-2B-4bit`. The selected 4-bit model is approximately 1.72 GB and is Apache-2.0 licensed. The model card and license were checked before wiring the runtime. MLX Swift LM 3.31.4 lists Qwen3.5 text support.

In Settings, **Download model** begins the download and preparation. Kio stores the Hugging Face cache under `~/Library/Application Support/Kio/Models`. The model is loaded only after that explicit action or when a later request needs model planning. **Unload when idle** defaults to **Keep loaded**; the user can choose 5, 15, or 30 minutes. Removing the model deletes only Kio's cached copy; it can be downloaded again.

The fast deterministic planner remains first. When a request needs model planning, Kio sends the local model the request and a short list of file indexes, names, types, and sizes. It does not send file contents or local paths to the planner. The pinned MLX Swift LM 3.31.4 release supports Qwen3.5 tool-call parsing; Kio provides a `submit_plan` JSON-schema tool and reads its arguments without dispatching it. The pinned release does not include grammar-constrained JSON generation. The newer `MLXGuidedGeneration` package is on the upstream development branch, so Kio does not add an unreleased dependency. A strict typed decoder validates every operation, source, input kind, and argument. Kio makes one repair attempt after an invalid response and never executes a partial plan. There is no cloud fallback or arbitrary command execution.

Scribe is a separate local-model feature. When explicitly asked to summarize, rewrite, proofread, translate, extract points/actions, convert to Markdown, compare, or explain a selected text file, Kio reads its text locally and passes bounded chunks to the local model. Each source is limited to 4 MB of UTF-8 text; chunks are capped at 9,000 characters with overlap, and the output is limited to 2 MB. Scribe treats source content as untrusted data, writes a separate Markdown result, and leaves the input unchanged. These content limits apply to Scribe, not to ordinary planning, which still receives metadata only.

The 1.72 GB download and inference were exercised in the built app on Apple Silicon. With a one-pixel PNG attached, the request “Please turn this picture into a portable document page that I can print” went through local model planning, decoded to the registered image-to-PDF workflow, and produced a verified 5 KB PDF. The conversation and output reference were then restored from local history after quitting and reopening Kio. This was a focused smoke workflow; it does not validate every natural-language phrasing or every supported tool through model planning.

To repeat the smoke workflow, open Settings, choose **Load local model**, attach an image, and ask for a portable document page without saying “PDF” (the deterministic PDF fast path is intentionally bypassed). The raw model is not downloaded by `scripts/check.sh`; it is a large, explicit first-use download.
